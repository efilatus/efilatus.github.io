# Угадай, кто ты

Браузерная игра: каждому игроку выпадает карточка персонажа, он видит карточки всех, кроме своей, и угадывает себя вопросами «да/нет». Регистрации нет: игрок вводит имя и код стола, каждое устройство считается отдельным игроком.

## Как играют
1. Все открывают сайт и вводят один код стола. Первый севший становится хостом.
2. Хост отмечает одну или несколько тем и жмёт «Начать игру»: всем раздаются разные карточки.
3. Чужие карточки видны, своя скрыта. «Я угадал» открывает карточку и добавляет очко.
4. Хост жмёт «Закончить игру»: карточки сбрасываются, счёт остаётся, темы выбираются заново.

## Как устроено
- Статичный сайт для GitHub Pages: `index.html`, `config.js` (адрес и публичный ключ Supabase).
- Каталог лежит в Supabase: таблицы `themes` (темы) и `cards` (имя, подпись «откуда», тема). Создаются и наполняются скриптом `supabase-setup.sql`. Читать каталог может любой, менять только владелец проекта.
- Кто за столом, у кого какая карточка и счёт передаются между устройствами через Supabase Realtime и в базу не пишутся.
- Хост (севший первым) раздаёт карточки. Если хост уходит, хостом становится следующий; кто пришёл посреди игры, получает карточку от хоста.

## Как добавить темы и карточки
Supabase → Table Editor → `themes` или `cards` → Insert row. Правка кода и новая загрузка сайта не нужны.
- `themes`: `id` (латиницей), `name` (название для игроков), `sort` (порядок).
- `cards`: `theme_id`, `name`, `source` (то, что пишется в скобках). `name` не должно повторяться.

## Ограничения
- Своя карточка скрыта только в интерфейсе: её можно найти в инструментах разработчика браузера.
- Игрок, закрывший страницу, пропадает со стола; при возвращении садится со своей карточкой и счётом.
- Бесплатный проект Supabase ставится на паузу после недели без активности; его снова включают в панели Supabase.

`archive-node-server/` в проекте — предыдущая версия с собственным Node-сервером.
