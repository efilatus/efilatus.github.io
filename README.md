# Угадай, кто ты

Браузерная игра: каждому игроку выпадает карточка персонажа, он видит карточки всех, кроме своей, и угадывает себя вопросами «да/нет». Регистрации нет: игрок вводит имя и код стола, каждое устройство считается отдельным игроком.

## Как устроено
- Статичный сайт для GitHub Pages: `index.html`, `cards.js` (набор карточек), `config.js` (адрес и публичный ключ Supabase).
- Игроки за столом видят друг друга через Supabase Realtime (presence). Таблицы в базе не нужны.
- Карточка, счёт и время входа игрока хранятся на его устройстве (localStorage) по коду стола, поэтому после перезагрузки страницы всё сохраняется.

## Настройка
1. Создать проект на supabase.com (бесплатный план).
2. В `config.js` вписаны Project URL и publishable key.
3. Включить GitHub Pages для репозитория (Settings → Pages → Deploy from branch, папка `/`).

## Ограничения
- Сервера нет, поэтому свою карточку технически можно подсмотреть в инструментах разработчика браузера.
- Игрок, закрывший страницу, пропадает со стола; при возвращении садится со своей карточкой и счётом.
- Бесплатный проект Supabase ставится на паузу после недели без активности; его снова включают в панели Supabase.

`archive-node-server/` — предыдущая версия с собственным Node-сервером (для хостинга вроде Render).
