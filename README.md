# Угадай, кто ты

Браузерная игра: каждому игроку выпадает карточка персонажа, он видит карточки всех, кроме своей, и угадывает себя вопросами «да/нет». Регистрации нет: игрок вводит имя и код стола, каждое устройство считается отдельным игроком.

## Как устроено
- Статичный сайт для GitHub Pages: `index.html`, `cards.js` (набор карточек), `config.js` (сервер знакомств).
- Первое устройство за столом становится хостом: хранит состояние стола и рассылает каждому игроку вид стола без его собственной карточки. Остальные подключаются к хосту напрямую (WebRTC через PeerJS).
- Бесплатный общедоступный сервер PeerJS нужен только чтобы устройства нашли друг друга.
- Если хост уходит, хостом становится другой игрок; карточки и счёт остальных сохраняются, новый хост получает новую карточку.
- Игрок, свернувший браузер или перезагрузивший страницу, держит своё место 10 минут.

## Ограничения
- В некоторых сетях (часть мобильных операторов, корпоративный Wi‑Fi) прямое соединение не устанавливается: для этого нужен TURN-сервер.
- Хост технически может подсмотреть свою карточку в инструментах разработчика.
